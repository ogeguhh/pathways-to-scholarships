# Pathways to Scholarships

ICS 325 Final Project — Fall 2026

## Project Overview

Pathways to Scholarships is a web application designed to help middle and high school students and their families find scholarships based on state, grade level, and field of study.

## Required Technologies

- HTML5
- CSS3
- JavaScript
- jQuery
- Bootstrap 5
- PHP 8.x
- MySQL 8.x
- PDO prepared statements

## Development

This project follows the professor's 10-iteration development plan.

Current iteration: Iteration 1 — Project Setup, Requirements, and Design.

## Team Workflow

Development work is completed on feature branches and merged into main through reviewed pull requests.
