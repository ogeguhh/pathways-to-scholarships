# Pathways to Scholarships — User Stories

## Iteration 1 — Requirements and Design

These user stories describe the functionality required for the five application roles.

## 1. Visitor (3 Stories)

**US-V01:** As a visitor, I want to search scholarships by state, grade level, and field of study so that I can find opportunities relevant to a student.

**US-V02:** As a visitor, I want to view scholarship details, including eligibility, award amounts, deadlines, and the official provider URL, so that I can understand how to apply.

**US-V03:** As a visitor, I want to read the About and FAQ pages and submit a Contact form so that I can learn about the website and ask questions.

## 2. Student (5 Stories)

**US-S01:** As a student, I want to register and log in so that I can access my personal scholarship features.

**US-S02:** As a student, I want to maintain my grade level, state, and fields of interest so that the website can identify relevant scholarships.

**US-S03:** As a student, I want to view scholarships matching my profile so that I can find opportunities suited to my eligibility and interests.

**US-S04:** As a student, I want to save and unsave scholarships so that I can return to opportunities I am interested in.

**US-S05:** As a student, I want to track application statuses and upcoming deadlines so that I can manage my scholarship applications.

## 3. Parent (5 Stories)

**US-P01:** As a parent, I want to register and log in so that I can manage scholarship information for my children.

**US-P02:** As a parent, I want to create, edit, and remove child profiles so that I can manage each child's grade, state, and interests.

**US-P03:** As a parent, I want to see scholarship matches for each child so that I can identify opportunities appropriate for them.

**US-P04:** As a parent, I want to save scholarships for individual child profiles so that I can organize opportunities separately.

**US-P05:** As a parent, I want to track application statuses and upcoming deadlines for my children so that I can help them complete applications on time.

## 4. Administrator (5 Stories)

**US-A01:** As an administrator, I want to upload CSV and Excel scholarship files so that I can add research collected by the Data Science class.

**US-A02:** As an administrator, I want to review validation errors, warnings, and duplicates before importing records so that the dataset remains accurate.

**US-A03:** As an administrator, I want to commit and roll back import batches so that I can control changes to the scholarship dataset.

**US-A04:** As an administrator, I want to create, edit, verify, and archive scholarships so that I can maintain accurate information.

**US-A05:** As an administrator, I want to manage scholarship providers and review data quality reports so that I can identify and correct data problems.

## 5. Super-admin (3 Stories)

**US-SA01:** As a super-admin, I want to create and manage user accounts and roles so that each user receives the appropriate permissions.

**US-SA02:** As a super-admin, I want to manage reference data such as states, grades, categories, fields of study, provider types, and national themes so that scholarship information remains consistent.

**US-SA03:** As a super-admin, I want to view the audit log so that I can review important administrative actions and changes.
