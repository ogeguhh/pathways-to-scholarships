## Notes

All scholarship examples are fictional placeholders.

State, grade level, and field of study are mandatory search filters.

Expired scholarships are hidden by default.

Results will update using jQuery AJAX without a full page reload.

Desktop results use a table; mobile results use cards.

Search functionality will be implemented in Iteration 5.
