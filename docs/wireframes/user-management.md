## Notes

All users shown are fictional placeholders.

Only Super-admins can access User Management.

Super-admins can create accounts for all permitted roles.

The system must prevent demoting or deactivating the last active Super-admin.

Password resets require the user to change the temporary password at next login.

The functional User Management page will be implemented in Iteration 7.
