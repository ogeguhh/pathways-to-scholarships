# Pathways to Scholarships – User Stories

## Student User Stories

### STU-01 – Search Scholarships
As a student, I want to search for scholarships so that I can find opportunities I may qualify for.

### STU-02 – Filter Scholarships
As a student, I want to filter scholarships by grade level, location, and field of interest so that I can find scholarships that match me.

### STU-03 – View Scholarship Details
As a student, I want to view scholarship details so that I can understand the requirements, award amount, and deadline.

### STU-04 – View My Matches
As a student, I want to see scholarships that match my information so that I can find scholarships that fit me more easily.

### STU-05 – Create an Account
As a student, I want to create an account so that I can save my information and use personalized scholarship features.


## Parent User Stories

### PAR-01 – Search Scholarships
As a parent, I want to search for scholarships so that I can help my child find opportunities they may qualify for.

### PAR-02 – Filter Scholarships
As a parent, I want to filter scholarships by my child's grade level, location, and interests so that I can find relevant opportunities.

### PAR-03 – View Scholarship Details
As a parent, I want to view scholarship details so that I can understand the requirements, award amount, and deadline.

### PAR-04 – View Matches
As a parent, I want to view scholarships that match my child's information so that I can help them find good opportunities.

### PAR-05 – Create an Account
As a parent, I want to create an account so that I can use the scholarship matching features.


## Administrator User Stories

### ADM-01 – View Scholarships
As an administrator, I want to view the scholarships in the system so that I can manage the scholarship information.

### ADM-02 – Import Scholarships
As an administrator, I want to import scholarship data so that multiple scholarships can be added to the system.

### ADM-03 – Review Import Results
As an administrator, I want to view an import validation report so that I can see if there are errors in the imported scholarship data.

### ADM-04 – Edit Scholarships
As an administrator, I want to edit scholarship information so that incorrect or outdated information can be updated.

### ADM-05 – Manage Scholarship Information
As an administrator, I want to manage scholarship records so that users receive accurate scholarship information.


## Visitor User Stories

### VIS-01 – View Home Page
As a visitor, I want to view the home page so that I can understand what the website provides.

### VIS-02 – Search Scholarships
As a visitor, I want to search available scholarships so that I can see what opportunities are available before creating an account.

### VIS-03 – Register
As a visitor, I want to register for an account so that I can access personalized features such as scholarship matches.


## Super-Admin User Stories

### SA-01 – Manage Users
As a super-admin, I want to view and manage user accounts so that I can control who has access to the system.

### SA-02 – Manage Administrators
As a super-admin, I want to manage administrator accounts so that the correct people have administrative access.

### SA-03 – Manage User Roles
As a super-admin, I want to manage user roles so that each user has the correct level of access.
